# 09.09.2026

MSTC combined bid sheet workbook with a live grouped search.

## Files

- **Search any withot error.xlsx** — the workbook.
  - *Final Calculation Sheet*: 37 lots with all calculations; row-3
    filter arrows sort ascending/descending (totals stay out of the
    sort range).
  - *Live Search*: type-to-filter dashboard. New **sort toggle**:
    pick a column in the SORT BY box (cell AJ2, just right of the
    table) and a direction in ORDER (AL2); the sorted header shows
    ▲/▼ and rows reorder inside each group while every total row
    stays in place. See the in-sheet instructions (row 2).
- **SortToggle.bas** — optional VBA module for true one-click
  sorting: click a column header to sort, click again to flip.
- **SORT_TOGGLE_SETUP.md** — how to use the sort toggle and how to
  install the optional click-on-header macro.
